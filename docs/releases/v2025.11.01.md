# v2025.11.01 – 2025-11-04

## New Features

### Smart Time Countdown

The board now intelligently switches between time units based on proximity to the holiday:

- **Less than 24 hours**: Displays countdown in **hours** (e.g., "5 HOURS TIL")
- **Less than 1 hour**: Displays countdown in **minutes** (e.g., "45 MINUTES TIL")
- **24+ hours away**: Displays countdown in **days** (e.g., "3 DAYS TIL")
- **Today**: Shows **"TODAY IS"** with the holiday name (no countdown number)

### Custom Holidays Only Mode

New `custom_holidays_only` configuration option allows you to display only your personal holidays from the CSV file:

```json
{
  "custom_holidays_only": true
}
```

When enabled, the board skips the holidays library entirely and shows only holidays defined in your `custom_holidays.csv`. Perfect for creating a personal countdown display for birthdays, anniversaries, and special events.

### Animation Toggle

New `animation` configuration option to control text rendering behavior:

```json
{
  "animation": true
}
```

- **`true` (default)**: Original animated text reveal with phased rendering (shows one line at a time)
- **`false`**: Displays all text elements at once for faster display

### New Holiday Themes

Added themed images and colors for:

- **Groundhog Day** - Golden text with festive groundhog image
- **Veterans Day** - Patriotic green text with memorial image

## Configuration Updates

### Updated `config.sample.json`

New configuration options available:

```json
{
  "country_code": "US",
  "subdiv": "NY",
  "categories": ["GOVERNMENT", "UNOFFICIAL"],
  "ignored_holidays": ["Columbus Day"],
  "horizon_days": 90,
  "themes_path": "holiday_themes.json",
  "custom_holidays_path": "custom_holidays.csv",
  "display_seconds": 5,
  "animation": true,
  "custom_holidays_only": false,
  "enabled": true

```

## Upgrade Instructions

**Follow these steps in order:**

### ‼️ Important ‼️

There is a bug in the plugin upgrade process that might cause customized data to be removed.  Most often, custom images. Please ensure you have a copy you can restore before upgrading.  This should be fixed in the next release of the scoreboard.

### 1. Fix Permissions and Clear Cache Before Updating

```bash
cd $HOME/nhl-led-scoreboard
./scripts/sbtools/sb-cleanup-cache -d -f
```

**Why:** Root-owned cache files will prevent the plugin from upgrading.

**Important:** ⚠️ Do this before step 2.

### 2. Update Plugin

**If already installed:**

```bash
python plugins.py sync
```

**New installation:**

```bash
python plugins.py add https://github.com/kas21/nls-plugin-holiday-countdown-board.git
```

### 3. Update Configuration (Optional)

Add new options to `src/boards/plugins/holiday_countdown_board/config.json`:

```json
{
  "animation": true,
  "custom_holidays_only": false
}
```

See [config.sample.json](../../config.sample.json) for full example.

### 4. Add New Holiday Themes (Optional)

If you want to use the new Groundhog Day and Veterans Day themes, they're already included. Just make sure these holidays aren't in your `ignored_holidays` list.

### 5. Restart Scoreboard

Example if using Supervisor:

```bash
sudo supervisorctl restart scoreboard
```

- Changes to holiday_themes.json will be overwritten by defaults
